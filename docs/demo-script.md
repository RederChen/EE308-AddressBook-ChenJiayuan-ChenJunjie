# 完整演示视频脚本与录制清单

> 目标是录制一段不跳剪关键步骤的完整运行演示。建议 5–7 分钟、1280×720 或更高、能看见鼠标和提示。视频中只使用项目自带的虚构数据。

## 录制前

1. 执行 `python -m pip install -r requirements.txt`、`python seed_demo.py`、`python app.py`。
2. 打开 `http://127.0.0.1:5000`，准备 Excel/WPS 和 `sample_data/contacts_sample.xlsx`。
3. 若需从空库演示，先备份并移走本地 `instance/addressbook.db`，再启动应用；不要在未备份时删除数据。
4. 清空浏览器无关标签与桌面隐私信息，开始录屏后先展示课程、团队名称和日期。

## 镜头与讲解

### 00:00–00:30 启动和概览

展示终端启动命令、健康页面及首页。口播：“本项目使用 Flask、SQLite 和 OpenPyXL，实现收藏、多联系方式与 Excel 导入导出。当前所有演示联系人均为虚构。”

### 00:30–01:20 新建与多联系方式

点击“新建联系人”，姓名填写“演示同学”，添加两条手机、一个邮箱、微信和地址，填写备注并勾选星标。保存后打开详情，逐条展示，证明同类型联系方式不互相覆盖。

### 01:20–02:00 收藏、筛选与搜索

取消再恢复星标；进入“星标联系人”确认可快速访问；搜索第二条手机号，确认能定位。随后编辑该联系人，修改邮箱并保存，展示更新结果。

### 02:00–02:40 Excel 导出

点击“导出 Excel”，在 Excel/WPS 打开文件。展示中文表头、每位联系人一行、多个手机以中文分号分隔、收藏“是/否”、冻结表头与筛选按钮。

### 02:40–03:40 Excel 导入

回到应用下载标准模板，展示格式。导入 `contacts_sample.xlsx`；若数据已存在，展示同名跳过反馈。为了演示新增，可在导入文件中新增一位虚构联系人“导入演示”。导入后搜索该姓名并打开详情。

### 03:40–04:30 异常与原子性

制作或提前准备一份第二行有效、第三行缺姓名的 `.xlsx`。上传后展示“第 3 行”错误及“整批未写入”；搜索第二行姓名证明没有部分导入。再上传 `.csv` 展示格式限制。

### 04:30–05:10 删除与响应式界面

删除“演示同学”，展示二次确认和列表更新。缩小浏览器宽度或使用手机模拟，展示导航、卡片和编辑对话框仍可使用。

### 05:10–05:50 测试与工程证据

终端执行 `python -m pytest`，展示 26 项通过。打开 GitHub Commits、至少三次真实提交、两位成员贡献、Pull Request 和 Release 页面。不要用本地假提交冒充团队证据。

### 05:50–06:10 结束

展示源码目录、README 与代码规范。若实际部署了云版本，再访问公网链接并重复一个核心操作；localhost 不作为云部署证据。

## 录制后

- 文件建议命名：`evidence/video/address-book-demo.mp4`。
- 从头播放确认有声音、文字清晰、操作完整、无隐私信息。
- 上传至可公开访问的视频平台或网盘，将真实 URL 填入个人博客。
- 至少截取：首页、多联系方式编辑、收藏筛选、Excel 导出内容、导入成功、导入异常、测试通过、GitHub 历史。
