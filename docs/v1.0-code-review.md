# V1.0 代码审查报告

审查日期：2026-11-16。基线来源为用户提供的 `拾光通讯录_作业交付.zip`；本报告只描述实际检查结果，不把原有功能算作 V1.1 新增。

## 结构与运行

- `app.py` 为 Flask 启动入口；`addressbook/` 分为应用工厂、数据库、仓储、校验、Excel 与路由模块。
- `templates/index.html`、`static/styles.css`、`static/app.js` 构成原生前端；`tests/` 有 pytest 测试；`docs/` 包含设计、代码规范、协作和原测试报告；另有示例工作簿、种子数据脚本和 Dockerfile。
- 实际依赖由 `requirements.txt` 确认为 Flask 3.1.2、OpenPyXL 3.1.5、pytest 8.4.2，数据库为 SQLite。Python 3.13.12 的隔离环境中安装依赖后，V1.0 原包 **17 项测试通过**；Flask 服务可启动。

## 已实现功能

- 联系人增删改查、收藏筛选、关键词搜索、多条联系方式，以及 8 种联系方式类型均已存在。
- `contacts` 与 `contact_methods` 为一对多关系；后者原本已有 `label TEXT NOT NULL DEFAULT ''`。后端校验、创建、更新、查询和详情 API 已支持标签，详情模板渲染也已支持显示。
- Excel 导入/导出、模板、同名跳过与整批校验已实现；原格式为每人一行的 11 列主表。V1.0 的导出没有写入联系方式标签，重新导入会丢失标签。
- 原测试覆盖主体功能，但没有验证前端标签编辑，也没有验证标签在 Excel 往返后的保留。

## 发现的问题与 V1.1 取舍

| 优先级 | 发现 | 影响 | V1.1 处理 |
|---|---|---|---|
| 高 | 前端动态联系方式行只有类型和值；保存请求不带 `label` | 原标签在编辑保存后变成空字符串，用户无法从界面创建或修改标签 | 补输入框、回填和提交，增加浏览器验收与回归测试 |
| 中 | Excel 主表不保存标签 | 导出再导入会丢失标签 | 保持原 11 列，增加可选标签工作表；旧模板照常导入 |
| 中 | 旧数据库若没有 `label` 列，仅 `CREATE TABLE IF NOT EXISTS` 无法升级 | 查询旧数据时会因缺列失败 | 启动时执行最小增量迁移 |
| 低 | 搜索使用 `LIKE`，输入 `%`、`_` 会作为通配符 | 特殊字符搜索结果可能超出字面匹配 | 本版未改；后续可加转义 |
| 低 | Excel 导出将用户文本直接写入单元格 | 以 `=` 开头的文本可能被 Excel 当成公式 | 本版未改；后续应统一转义并评估往返兼容 |
| 低 | 本地版无账号和多用户隔离 | 不适合直接公开部署 | 保留原有本地使用定位 |

V1.1 没有重做联系人 CRUD、收藏、搜索或基础 Excel 主表。原 `docs/` 中的协作、PSP、博客和 GitHub 占位记录属于 V1.0 随包材料，不能作为本次开发的真实贡献或提交证据。

用户提供的课程页面链接在本次环境中未能直接打开；交付范围依据用户在本聊天中列出的验收要求和压缩包内实际代码确定。
