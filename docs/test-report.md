## 3. 缺陷与回归

模板下载初版在重新读取工作簿前调用了 `workbook.close()`，使 `BytesIO` 一并关闭，触发 `ValueError: I/O operation on closed file`。修复为从空模板流读取、追加示例、另存输出流后关闭工作簿。修复后全部 17 项测试通过。

## 5. 已知边界

- 支持 `.xlsx`，不支持旧 `.xls` 和 CSV；单个文件最大 5 MiB。
- 同名导入采用跳过策略，不提供覆盖合并。
- 当前本地版无登录和多用户隔离，公网部署前必须补充认证、HTTPS、备份与生产 WSGI。
- 截图工具异常不能替代人工验收，完整运行视频和 GitHub 证据仍须团队真实录制/操作。
