# Personal Software Process（PSP）

> 两名成员分别记录自己的实际时间（分钟）。计划值在任务开始前填写，实际值在完成后填写；不可两人共用同一组数字。下表结构可直接复制到个人 CSDN 博客。

## 成员 A：【姓名/学号待填写】

| PSP 阶段 | 计划耗时（分钟） | 实际耗时（分钟） | 工作内容/证据 |
|---|---:|---:|---|
| Planning 计划 | 【待填写】 | 【待填写】 | 阅读要求、估算任务、拆分模块 |
| Estimate 估算 | 【待填写】 | 【待填写】 | 估计设计、编码、测试时间 |
| Development 分析 | 【待填写】 | 【待填写】 | 数据模型、接口与异常场景分析 |
| Development 设计 | 【待填写】 | 【待填写】 | 收藏、多联系方式、Excel 方案设计 |
| Development 设计复审 | 【待填写】 | 【待填写】 | 与搭档交叉检查设计 |
| Development 编码 | 【待填写】 | 【待填写】 | 【填写本人实际模块】 |
| Development 代码复审 | 【待填写】 | 【待填写】 | 自审与搭档 PR 审查 |
| Development 测试 | 【待填写】 | 【待填写】 | 单元/集成/界面测试与修复 |
| Postmortem 总结 | 【待填写】 | 【待填写】 | 博客、PSP、贡献与问题总结 |
| **合计** | **【待计算】** | **【待计算】** | 各阶段纵向求和 |

缺陷记录（建议填写）：引入阶段、发现阶段、修复耗时、缺陷描述、修复 commit。
